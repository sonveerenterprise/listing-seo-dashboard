# Security policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Don't open a public issue for security problems.

Include what you found, where (file or URL path), and how to reproduce it. You'll get an acknowledgement through the
same private report.

## Scope

This repository is the web dashboard only. It is a client of the hosted Listing SEO core service, which is not part
of this repository. Reports about the dashboard code are welcome here; for the hosted service, use the same private
reporting channel and say so in the report.

## Supported versions

Only the latest commit on `main` is supported.
